# Code Review Adjudication Ledger

Every finding here has already been ruled on by the maintainer. Reviewers MUST NOT re-report these or close variants of them. A new finding adjacent to an entry must cite the entry ID and explain what is materially different (different file, trigger, or consequence). Disagreement with an adjudication is not a finding.

Maintenance: after each review cycle, append one row per finding that was rejected, accepted as a risk, or resolved as by-design. Fixed findings do not need rows — the dated review files in this directory record them. IDs are `L-NN`, never reused.
